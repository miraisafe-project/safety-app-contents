ミライセーフ プライバシーポリシー

ミライセーフプロジェクト（以下「運営者」といいます。）は、アプリ「ミライセーフ」（以下「本アプリ」といいます。）における利用者に関する情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

1. 運営者

運営者：ミライセーフプロジェクト

運営者の氏名、住所その他法令に基づき開示が必要となる情報については、本ポリシーに記載するお問い合わせ窓口から適切な請求があった場合、本人確認その他必要な確認を行ったうえで、法令に従い遅滞なく回答します。

2. 本アプリが直接取得しない情報

本アプリには、アカウント登録またはログイン機能はありません。

また、本アプリ自体が利用者の氏名、メールアドレス、電話番号その他これらに類する情報を直接取得して運営者のサーバーへ送信する機能はありません。

広告、アクセス解析およびクラッシュ解析のためのサービスは、現在利用していません。

3. 端末内に保存する情報

本アプリでは、機能の提供および利便性向上のため、以下の情報を利用者の端末内に保存します。

既読状態

以下のコンテンツのID等を保存します。

  • ケースファイル
  • みんなの体験談
  • お知らせ
  • 「知っておきたいこと」の授業

ブックマーク状態

以下のコンテンツのID等を保存します。

  • ケースファイル
  • みんなの体験談
  • お知らせ

表示設定

ふりがなのON・OFF設定を保存します。

この設定は、ふりがな表示に対応する画面で共通して使用されます。

チュートリアル表示状態

初回起動時のチュートリアルを表示済みであるかどうかを示す情報を保存します。

コンテンツのキャッシュ

GitHub Pagesから取得した以下のコンテンツを、表示およびオフライン時等の利用のため端末内に一時的に保存する場合があります。

  • ケースファイル
  • みんなの体験談
  • お知らせ

保存されるデータには、記事ID、カテゴリ、タイトル、本文、公開日、更新日その他コンテンツの表示に必要な情報が含まれます。

更新確認用の情報

コンテンツの更新確認のため、バージョン、カテゴリファイル名、更新日時その他index.jsonに含まれる情報を保存します。

また、ケースファイルおよび「みんなの体験談」等について、最後に更新確認を行った日時を保存する場合があります。

これらの情報は原則として利用者の端末内に保存され、運営者へ送信されません。

アプリを削除した場合などには、これらの情報が失われることがあります。

4. 体験談の投稿

本アプリでは、Googleフォームを利用して体験談の投稿を受け付けています。

体験談の投稿は匿名であり、投稿フォームには氏名、メールアドレス、電話番号等を入力するための欄を設けていません。

投稿者には、個人名、学校名、住所、SNSのアカウント名その他、本人または関係者を特定できる情報を投稿しないようお願いしています。

投稿された内容は、以下の目的で利用します。

  • 投稿内容の確認
  • 本アプリの「みんなの体験談」への掲載
  • 個人が特定されないようにするための編集
  • 投稿の趣旨を変えない範囲での表現変更、簡略化または再構成
  • 複数の投稿をもとにした体験談の作成
  • ミライセーフプロジェクトのWebサイト、SNS、広報資料その他関連活動での紹介
  • 不適切な投稿、迷惑行為等への対応

すべての投稿が掲載されるものではありません。

匿名での投稿となるため、掲載後に削除または修正の申し出があった場合でも、投稿者本人であることを確認できない場合などには、ご希望に沿えないことがあります。

5. お問い合わせにおいて取得する情報

本アプリでは、Googleフォームを利用してお問い合わせを受け付けています。

お問い合わせフォームでは、以下の情報を取得する場合があります。

  • お問い合わせ本文
  • 使用している端末に関する情報（任意）
  • OSのバージョン（任意）
  • 返信先メールアドレス（任意）

取得した情報は、以下の目的で利用します。

  • お問い合わせ内容の確認および対応
  • お問い合わせへの返信
  • アプリの不具合や問題の調査
  • 本アプリの改善

返信先メールアドレスは、お問い合わせへの返信およびそれに付随する対応のために利用し、これらと無関係な広告、宣伝等には利用しません。

6. 情報の保存期間

Googleフォームを通じて取得した情報その他運営者が保有する情報は、その利用目的を達成するために必要な期間保存します。

利用目的との関係で保有する必要がなくなった情報については、法令その他正当な理由により保存が必要な場合を除き、適切な方法による削除に努めます。

7. Googleフォームの利用

本アプリでは、体験談の投稿およびお問い合わせの受付にGoogleフォームを利用しています。

Googleフォームを利用する際には、Google LLCが提供するサービスを経由して情報が送信されます。

Googleによる情報の取扱いについては、Googleが定めるプライバシーポリシーその他の規定が適用されます。

外部サービスの利用に伴い、当該サービス提供者が、IPアドレス、端末情報その他サービスの提供・安全管理等に必要な情報を取得する場合があります。

8. GitHub Pagesの利用

本アプリでは、ケースファイル、「みんなの体験談」、お知らせその他のコンテンツの配信、および利用規約・プライバシーポリシー等のWebページの公開にGitHub Pagesを利用します。

GitHub Pagesへのアクセスに伴い、サービス提供者であるGitHub, Inc.が、セキュリティその他サービス提供上の目的のために、利用者のIPアドレスその他のアクセス情報を取得・保存する場合があります。

これらはGitHubによる情報の取扱いであり、運営者は本アプリに独自のアクセス解析機能を導入していません。

GitHubによる情報の取扱いについては、GitHubが定めるプライバシーに関する規定が適用されます。

9. 第三者への提供

運営者は、取得した個人情報を、次の場合を除き、本人の同意なく第三者に提供しません。

  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要があり、本人の同意を得ることが困難な場合
  • その他、個人情報保護法その他の法令により認められている場合

なお、本ポリシーに記載したGoogleフォームその他の外部サービスを利用する場合には、サービスの提供に必要な範囲で外部サービス提供者によって情報が取り扱われることがあります。

10. 情報の安全管理

運営者は、取得した個人情報について、漏えい、滅失、毀損、不正アクセスその他の事故を防止するため、取り扱う情報の内容および規模に応じて、必要かつ適切な安全管理措置を講じるよう努めます。

安全管理措置の詳細について、法令に基づき回答が必要な場合には、お問い合わせ窓口からの請求に応じて適切に対応します。

11. 個人情報に関する請求

利用者本人から、運営者が保有する本人の個人情報について、利用目的の通知、開示、訂正、追加、削除、利用停止その他法令に定められた請求があった場合には、本人確認その他必要な確認を行ったうえで、法令に従い対応します。

匿名で投稿された体験談など、運営者が投稿者本人を識別できない情報については、本人確認ができないこと等により対応できない場合があります。

請求については、アプリ内の「お問い合わせ」からご連絡ください。

12. 外部リンク

本アプリには、相談機関その他の第三者が運営するWebサイトへのリンクが含まれる場合があります。

リンク先のWebサイトにおける情報の取扱いについては、それぞれの運営者が定めるプライバシーポリシー等をご確認ください。

13. 本ポリシーの変更

運営者は、法令の変更、本アプリの機能変更、利用する外部サービスの変更その他必要に応じて、本ポリシーを変更することがあります。

変更した場合は、GitHub Pages上に掲載する本ポリシーを更新し、最終改定日を表示する方法その他適切な方法により周知します。

利用者に大きな影響を与える変更を行う場合には、必要に応じて本アプリ内でもお知らせします。

14. お問い合わせ

本ポリシー、個人情報の取扱い、開示等の請求その他のお問い合わせは、アプリ内の「お問い合わせ」からご連絡ください。
